Termos de Uso e Política de Privacidade

Isenção de Responsabilidade

Este é um projeto estritamente acadêmico e de portfólio, desenvolvido com o objetivo de demonstrar competências técnicas em Engenharia de Software, Arquitetura de Sistemas com .NET 10 e boas práticas de desenvolvimento web.

  • Dados Fictícios: quaisquer valores, ativos, produtos, dados quaisquer exibidos ou inseridos na aplicação são meramente ilustrativos e simulados, não correspondendo a dados reais.
  • Uso Local: o software foi desenhado para execução em ambiente de desenvolvimento local (Sandbox) e não deve ser utilizado como um sistema oficial de estoques ou controle patrimonial real sem as devidas auditorias e adaptações de segurança de infraestrutura.

Termos de Uso e Política de Privacidade

Esta seção estabelece as diretrizes de transparência, privacidade e segurança relativas ao processamento de dados dentro desta aplicação de portfólio.

  • Armazenamento Local e Isolado: todos os dados cadastrados (como registros de produtos, fornecedores etc) são armazenados estritamente no banco de dados local (PostgreSQL rodando via Docker local ou na máquina de execução).
  • Ausência de Telemetria: a aplicação não possui rastreadores, cookies de terceiros, telemetria automatizada ou qualquer mecanismo de coleta oculta de metadados do sistema operacional ou do comportamento do usuário.
  • Nuvem e Servidores Externos: nenhuma informação inserida neste sistema é enviada, replicada ou compartilhada com servidores externos, APIs de terceiros ou serviços na nuvem.
  • Controle Total do Usuário: o usuário possui autonomia total sobre as informações, podendo purgar (limpar) o banco de dados completamente a qualquer momento, bastando derrubar ou resetar o volume do container Docker (docker compose down -v).
